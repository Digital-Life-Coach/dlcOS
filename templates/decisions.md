# Decisions

*Subject: **the past.** Answers: **What's settled, and why?***

*Canonical location for choices already made, with the reasoning attached. The point is to stop settled questions from being reopened every few months — by me, by a coach, or by an AI that doesn't know the history.*

*If an assistant is about to recommend something in this file, it should read the **Why** first and either respect it or argue with the actual reason.*

---

## How to use this file

One entry per decision, newest first. Keep the **Why** — a decision without its reasoning gets overturned the first time someone forgets it.

```
### <Short name of the decision> — YYYY-MM-DD

**Decided:** what was chosen, in one sentence.
**Why:** the reasoning. This is the part that matters.
**Revisit if:** the condition that would make this worth reopening. "Never" is a valid answer.
```
