# Thoughts




## Drop here ↓

*Reflections, observations, half-finished thoughts, conversations to remember, questions to sit with. Not actionable, not (yet) ideas — just stuff worth holding onto.*

**Routing heuristic** (Claude decides when this file is processed):
- Personal reflection / mood / introspection → daily journal entry
- Concept worth synthesizing / cross-linking → `Wiki/` (Phase 2 — for now, stays here)
- Quick observation about today → `Reference/Dailies/YYYY-MM-DD.md` (## Thoughts section)
- Actionable in disguise → `Inbox/ideas.md` or `Inbox/do-now.md`

If a question (ends in `?`), Claude tries to answer it inline.
