dlcOS Setup

Everything we install together, in order, on the Mac that will hold your AI workspace. Three apps, about twenty minutes, and then the setup wizard takes over.
~20 minutes Do it together on the call I run the terminal part

Read this first

Nothing here is technical. You download a couple of apps, sign in, and answer some questions. I handle the one piece that needs a command, and you can watch me do it.

Pick the Mac that stays home and stays on. This machine becomes the home of your second brain, so a desktop beats a laptop you carry around. (If you only have a laptop, that's fine too, it just means the workspace travels with you.)

Before we start

Three things to confirm before the call. Any one of these missing will stop us partway through, so it is worth two minutes now.

  • macOS 13 (Ventura) or newer. Click the Apple menu, then About This Mac. If you're older than that, tell me before the call and we'll sort the update out first.
  • Your Mac login password. The installers will ask for it.
  • Twenty uninterrupted minutes on the machine itself, not screen sharing from somewhere else.

What we're installing, and why

The install

1
Set up your account and install the apps

Ten minutes, and it has to happen first. The free Claude plan doesn't include the Code tab, which is the piece that does the real work. Everything after this depends on it.

  1. Go to claude.ai and sign in, or create an account if you don't have one.
  2. Open Settings → Billing and pick a plan. Pro is the right starting point for most people. Max is for heavy daily use, and you can move up later without redoing anything.
  3. Go to claude.ai/download, get the Mac version, open the download, drag Claude into Applications, and launch it. Sign in with the account you just made.
  4. On your phone, download Claude from the App Store and sign in with the same account. This is what lets you pick a session back up from your phone later.
Already have a Claude account? Check whether it's the free tier. Open Settings → Billing: if it doesn't say Pro or Max, it's free, and the Code tab won't open.
2
Create your vault folder, then I install dlcOS

Two minutes for the folder, five for my part. Everything you build lives in one plain folder of text files — that folder is the vault. Once it exists, I point dlcOS at it.

  1. In Finder, create a new folder wherever you want your workspace to live and give it a name (something like “Your Name Vault”). Your Documents folder is a fine location. Keep it at the root level rather than nested inside another folder — this tends to become your most-used folder over time.

Then it's my turn. The Claude app can't install plugins by itself, so this step runs a few commands in the Mac's built-in Terminal app (Applications → Utilities → Terminal). Watch if you're curious, or get a coffee — you won't need to type any of this yourself.

My checklist, in order — run each, confirm the expected result before moving on:

1. Check for git

$ git --version

Prints a version number → skip to step 3. Instead pops an "install developer tools" dialog, or errors with xcode-select: note: No developer tools were found → go to step 2.

2. Install Command Line Tools (only if step 1 needed it)

$ xcode-select --install

A GUI dialog pops up — accept it and wait for it to finish (several minutes, needs internet). This installs git, nothing more; ignore any suggestion to run xcode-select --switch, that's for a different situation. Don't install the full Xcode app for this.

3. Install the Claude Code CLI

$ curl -fsSL https://claude.ai/install.sh | bash

Installing dlcOS only works from here, not from inside the app.

4. Add the marketplace and install the plugin — type claude to start a session, then run these two:

> /plugin marketplace add Digital-Life-Coach/dlcOS
> /plugin install dlcOS@dlcOS

If step 4 fails with the xcode-select error, step 2 was skipped — go back and run it, then retry both lines above.

You'll know it worked when typing /dlcOS in the Claude app brings up a list instead of nothing.
3
Open the Code tab and run the wizard

This is the handoff. From here dlcOS walks you through the rest and I'm just along for the ride.

  1. In the Claude desktop app, click Code at the top of the window (the other two tabs, Chat and Cowork, are cloud-based — we're avoiding those for anything private).
  2. Choose Local when it asks about the environment.
  3. Click Select folder and choose the vault folder you created in step 2.
/dlcOS:setup

The wizard takes about forty five minutes and covers:

  • A few questions about who you are and what you want out of this.
  • Building out the rest of your vault.
  • Writing your memory, so Claude knows you in every future conversation instead of starting cold every time.
  • A walk through the four memory layers, so you understand where things get remembered and why.
  • A closing checklist of what to use when.
If clicking Code asks you to upgrade, you're signed in with a free account or the wrong one. Sign out, check Settings → Billing, and sign back in with the account from step 1.
Don't run this one on your own the first time. The wizard asks questions that are much easier to answer with me on the call, and getting your memory right at the start saves redoing it later.
4
Install Obsidian and open your vault

Two minutes, and now the last step — by now the wizard has already built out your vault, so there's something worth looking at.

  1. Go to obsidian.md/download and click the Mac download.
  2. Open the downloaded file, then drag the Obsidian icon into your Applications folder, and launch it.
  3. When it asks you to open a vault, choose Open folder as vault and select the same folder from step 2.

This is how you can see everything Claude has done. Every file it created or changed lives here as plain text, and you can read, edit, delete, or add to any of it yourself, any time — there's no mystery box.

Optional: add cmux, a nicer terminal

Skip this unless we talked about it. Step 2 already installed Homebrew, git, and the Claude Code CLI — you don't need any of that again. This just swaps the plain macOS Terminal app for cmux, a terminal built for running AI assistants. Worth doing if you want a dashboard that can start sessions for you, or if you like working in a terminal. We can always come back and add it later.

Install cmux

It needs macOS 14 (Sonoma) or newer.

  1. Go to cmux.com and click Download for Mac.
  2. Open the download, drag cmux into Applications, and launch it.
  3. Click through the welcome screen. You'll land on a window with a blinking cursor. Type claude and press return — since the CLI is already installed, it opens straight into a session.

After the wizard

You'll have a working setup and a handful of commands worth knowing. You don't have to memorize them: type /dlcOS: and the menu shows you everything, and plain English works for most of it too.

/dlcOS:endWrap up a session cleanly. Use this one every single time, even for a five-minute session — it's the habit that makes the rest work. See below.
/dlcOS:save-planPark something half finished so a future session can pick it up.
/dlcOS:resume-planPick that plan back up, with fresh eyes on it first.
/dlcOS:weekly-reviewThe Friday sweep through tasks and projects.
/dlcOS:monthly-reviewMonthly memory maintenance, so what Claude knows about you stays current.

Running a session, start to finish

The mechanics you'll use every time you sit down with Claude. None of this is complicated, but it's easy to forget in your first week, so it's worth reading once slowly.

Starting one

Click the + (New) button above your session list. Make sure it's creating the session inside your vault, not somewhere else — if you only have one vault, this is automatic. Then just tell it what you're there to do, in plain language.

Naming it

New sessions get a generic name. Double-click the name in the sidebar and type whatever the topic actually is, so you can find it again later.

Sending a turn

Each message you send is called a turn. Get all your thoughts out and send them together rather than firing off one short message, waiting, then sending another — that's slower and burns through your context faster. Hold Shift while you hit Return to add a new line without sending; a plain Return sends the whole thing.

Ending it — the step that matters most

When you're done, before you close the window or walk away, run:

/dlcOS:end

This is the command that actually writes what happened into your memory system: what you were working on, what you decided, what's still open. Skip it, and your next session starts cold with no idea what you just did — even a session that felt too short or trivial to bother with is worth ten seconds of /dlcOS:end. Plain /end works too, it's the same command.

Once it finishes, close out the session by going up to Archive. Archive keeps the session transcript on your hard drive so a future agent can look back at it if you ask it to. Delete removes that transcript entirely. Archive is the right default; only delete if you specifically want it gone for good.

Archiving without running /dlcOS:end first skips the memory-writing step — the transcript sits there, but nothing from it gets pulled into your vault's memory. Always /end, then archive.

Picking a session back up on your phone

Open the Claude app on your phone (the one you installed in step 1) and sign in with the same account. The default view is the regular chat interface — swipe over or use the sidebar to get to the Code tab, where your vault's sessions live. Tap the one you want, and it continues exactly where you left it.

This only works while the Mac running your vault is on and awake. Your phone isn't running the session itself, it's remote-controlling the one on your Mac — so if that machine is asleep or off, there's nothing to connect to.
